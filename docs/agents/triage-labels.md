# Triage labels

Matt skills use five canonical triage roles. This repository has not adopted a competing local vocabulary, so the canonical mapping is:

| Matt role | Repository label |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

This file maps vocabulary only; it does **not** authorize creating/changing GitHub labels during unrelated work.
