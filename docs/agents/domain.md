# Domain docs

This is a single-context Psoriasis donor/reference repository.

Before domain-sensitive work, read:

- `CONTEXT.md` for current system state and repository boundaries;
- `docs/INDEX.md` for current clinical/product authority;
- the specific contract/audit/plan linked from the index;
- relevant ADRs under `docs/adr/` if such ADRs are introduced later.

There is currently no required root `GLOSSARY.md`; do not create one ceremonially. Add durable vocabulary/ADR material only when a real term or decision needs a canonical home.

If a proposed change contradicts a current contract/audit/ADR, surface the conflict rather than silently overriding it.
